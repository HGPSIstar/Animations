Les cinq forces représentées sont les forces électromagnétiques sur les deux charges choisies. Elles ont une échelle commune, adaptée à l’affichage. Les traînées montrent le déplacement récent des porteurs : les électrons se décalent légèrement pendant le transitoire, puis gardent leur décalage en retrouvant une dérive horizontale. Le déplacement transverse est réduit graphiquement pour garder le dessin lisible. Les ions du réseau sont immobiles ; l’agitation thermique n’est pas représentée. Evolution ralentie.

A l’équilibre : jᵧ = 0 ; E⃗H = RH jₓ Bz uᵧ
Pour le conducteur : dF⃗L = j⃗ ∧ B⃗ dV

Modèle transitoire et conventionsUn seul type de porteurs : RH = 1/(nq). On impose jₓ ; E∥ s’ajuste pendant le transitoire pour maintenir ce courant. On suit la réponse transverse de Drude avec accumulation de charges aux faces isolantes. Le régime choisi est amorti critique (temps de relaxation diélectrique égal à 4τ). Le temps affiché est réduit ; il ne prédit pas la durée d’établissement dans un matériau particulier. e = γEᵧ/Jᵣₑf ; le courant est rapporté à Jᵣₑf. On choisit γ|RH|Bᵣₑf = 1. Pour la largeur w : UH = Vₐ − Vᵦ = −wEᵧ. La tension affichée est rapportée à wJᵣₑf/γ. Le schéma des forces reprend la page 10 du cours annoté : seules les actions électromagnétiques sont dessinées. Les interactions mécaniques entre les porteurs et le réseau ne figurent pas dans ce bilan des actions extérieures. La force magnétique comporte aussi une composante longitudinale pendant le transitoire, lorsque jᵧ est non nul.
