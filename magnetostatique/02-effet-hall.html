Animation 02 — L’établissement de l’effet Hall

De la déviation des porteurs à l’équilibre transverse

Réglages

Curseur logarithmique : de 10¹⁹ à 10²⁹ électrons par m³.

Porteurs mobiles : électrons (−e)
Réseau positif fixe
Section S = a b

Inverser B ou I recommence l’établissement.

Courant longitudinal imposé ; les faces latérales sont isolantes. Le champ de Hall s’établit par accumulation de charges.

Paramètres et sourcesValeurs représentatives vers 300 K. Le modèle conserve des électrons comme porteurs mobiles. En mode libre et pour le GaAs, RH = −1/(ne). Pour le GaAs, n = 10²¹ m⁻³ est choisi et la mobilité de dérive vaut 0,80 m²/(V·s) ; le facteur de Hall est pris égal à 1 dans ce modèle simple. Pour le cuivre, RH = −5,17·10⁻¹¹ m³/C et γ = 5,8·10⁷ S/m ; la densité nH = −1/(eRH) indiquée est une densité effective de Hall. En mode libre, la mobilité est fixée à 0,10 m²/(V·s), donc γ = neμ.

Les cinq forces représentées sont les forces électromagnétiques sur les deux charges choisies. Les flèches et le déplacement transverse sont amplifiés pour rendre le mécanisme visible ; leurs tailles ne permettent pas de comparer quantitativement deux matériaux. Les valeurs dans les panneaux sont, elles, calculées en unités physiques. Les traînées montrent le déplacement récent des porteurs : les électrons se décalent légèrement pendant le transitoire, puis gardent leur décalage en retrouvant une dérive horizontale. Le déplacement transverse est réduit graphiquement pour garder le dessin lisible. Les ions du réseau sont immobiles ; l’agitation thermique n’est pas représentée. L’avancement est une progression pédagogique ralentie, sans durée physique attribuée.

A l’équilibre : jᵧ = 0 ; E⃗H = RH jₓ Bz uᵧ
Pour le conducteur : dF⃗L = j⃗ ∧ B⃗ dV

Calculs et conventionsLe courant I est imposé suivant x. La section traversée est S = a b, d’où jₓ = I/(a b). Au régime établi, EH,y = RH jₓ Bz et UH = VA − VB = −a EH,y = −RH I Bz/b. A est sur la face supérieure (+y), B sur la face inférieure (−y) ; z sort de l’écran. Pour I > 0 et Bz > 0, EH,y < 0 et UH > 0. Les valeurs du champ et de la tension affichées suivent une interpolation monotone vers ces valeurs finales pendant l’établissement ; elle illustre l’accumulation des charges et ne prédit pas une durée d’établissement réelle. Les champs, tensions, paramètres matériaux et dimensions ont des unités physiques ; les flèches et les déplacements sont schématiques. Les seules forces dessinées sont les forces électromagnétiques ; les interactions mécaniques avec le réseau ne figurent pas dans ce bilan.
